# TryHackMe Writeups

Task-by-task walkthroughs from my TryHackMe journey, written to actually explain the concept behind each question, not just list answers. If you're stuck on a room, the goal is that reading the relevant section teaches you the reasoning, not just gives you the flag.

Current focus: SOC Level 1 path.
Each module folder matches TryHackMe's own path structure and task numbering, so you can follow along in the room itself while reading.

## Format:

Every writeup follows the room's own Task 1 / Task 2 / ... structure rather than a custom layout, so it's easy to cross-reference against the room directly.
Every quiz answer and flag is spoiler-tagged

(<details><summary>Answer</summary>...</details>,
click to reveal),

not written in plaintext next to the question. A couple of rooms in this path are subscriber-only content, this convention applies to all of them regardless, confirmed as acceptable directly with TryHackMe support.
Most writeups include a short Detection/Defense Note and Lessons Learned section, the parts meant to be useful beyond just finishing the room.
Screenshots live in each module's images/ folder and are referenced with relative paths.

## Why this exists

Documenting these properly forces me to actually understand the material instead of just clicking through it, and it doubles as something concrete to point to for anyone asking what I've actually done in security so far. If something in here is wrong or could be explained better, open an issue or a PR.
